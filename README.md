# Move Your Way

A playful sports and movement explorer for kids, built with plain HTML, CSS, and JavaScript. No frameworks, build step, accounts, or database.

## Open the site

Open `index.html` in a browser, or serve this folder using a local static HTTP server.

## Features

- 32 activity cards with explanations and tiny first steps
- Personality, time, energy, and space filters
- Removable filters and a Show all activities reset
- Favorites stored only in the visitor's browser
- Responsive layout and reduced-motion support

## Files

- `index.html`: page structure
- `style.css`: responsive styles
- `app.js`: activity content and interactions

Google Fonts supplies optional fonts; system fonts are used as a fallback. Activity icons use device emoji.

## Hosting

Any static host can serve these files. For GitHub Pages, select the `main` branch and `/ (root)` folder in repository Settings → Pages.
